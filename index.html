    How the MP3 download works

    1. Install the tools

      On your computer: git clone this repo and run bash convert.sh — it installs yt-dlp and ffmpeg (macOS: brew · Windows: winget · Linux: apt/dnf/pacman).

    2. Pick your video

      Watch it in the player above, then set your options — Copy writes the ready-to-run command for exactly that video to your clipboard.

    3. Run it locally

      Paste into a terminal on your own machine. yt-dlp pulls the stream, ffmpeg transcodes it, and an .mp3 lands in your folder. This website never touches your files.
